How the overall risk is calculated

  • Starts at the highest category in that day's column.
  • +1 level if two or more categories are orange or red the same day (stacked threats).
  • +1 level for the coastal-flood combo: high tide at medium or above and waves or swell at medium or above.
  • Capped at High. Days 8–10 are marked low confidence: wave and rain forecasts lose skill that far out.

Data sources (free, no key)

  • Rain, wind, gusts, pressure, CAPE: Open-Meteo Forecast API
  • Waves, swell: Open-Meteo Marine API
  • Tides: NOAA CO-OPS station 9413745 (Santa Cruz), MLLW. Falls back to Open-Meteo sea level if NOAA is unreachable.

Caveats

  • Tide is the predicted astronomical tide. Storm surge adds to it; watch NWS coastal flood alerts on big days.
  • Wave model point is just offshore of Capitola; open-ocean breaks run larger.
  • Thresholds are tuned for Capitola's south-facing exposure and are a starting point. Adjust the RULES table in the file to taste.
